# IPL-Data Analysis

## The aim of the project

The aim of the project is to analyze **Indian Premier League (IPL)** data to gain meaningful insights into teams, players, matches, runs, wickets, toss decisions, and season-wise performance.

## Here are some specific goals of an IPL dataset project in Python:

1. Identify the most successful teams and players in the IPL.
2. Analyze batting and bowling performances.
3. Analyze the impact of toss decisions on match outcomes.
4. Identify trends in IPL data over different seasons.
5. Analyze runs and wickets across IPL seasons.
6. Generate meaningful insights using data analysis and visualization.

## IPL Dataset

Data Analysis with IPL match-by-match and ball-by-ball datasets covering the seasons **2018–2026**.

The dataset contains two files:

1. `deliveries.csv`
2. `matches.csv`

## Analysis

* Highest run scorer in overall IPL
* Top wicket-taking bowlers
* Top-performing batsmen
* Top-performing bowlers
* Team-wise match wins
* Most successful IPL teams
* Total runs scored across seasons
* Total wickets taken across seasons
* Season-wise runs analysis
* Season-wise wickets analysis
* Number of tosses won by each team
* Most common decision after winning the toss
* Toss winner vs match winner analysis
* Player of the Match analysis
* Winning margin analysis
* Season-wise match analysis
* Team performance across seasons
